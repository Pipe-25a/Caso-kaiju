Caso organización Kaiju:

La organización Kaiju necesita mejorar el control y la trazabilidad de su inventario mediante una aplicación móvil Android para gestionar productos, movimientos de stock y ventas, reduciendo errores y quiebres de stock. 

Se Utilizo kotlin y andorid studios para la apliacion.
